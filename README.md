# ⚜️ LUXURY PRESTIGE — "YOUR FOCUS IS YOUR FORTUNE"

A bespoke, ultra-luxury one-page web experience crafted with **Royal Gold & Velvet Purple** aesthetics.

## ✨ Highlights
- **Interactive 3D Hero**: Three.js WebGL golden & velvet particle cosmos reacting to cursor motion.
- **Fluid Kinematics**: Lenis Smooth Scroll fully synchronized with GSAP ScrollTrigger ticker.
- **Parallax & Motion**: Staggered reveals, 3D card tilt interactions, and word-by-word text scrubbing.
- **Bespoke Theme System**: Seamless toggle between Haute Dark Velvet and Champagne Ivory Light mode.
- **Vercel Ready**: Static deployment architecture with clean URLs and instant load performance.
